2024 Backlog Preparation

Backlog-Specific Strategy

The 2024 Backlog paper contains the same eight set families, but the printed section blocks are reversed compared with the regular-guide convention used on this website. Use the mapping below before planning your 3-of-4 choices.

Critical: In the 2024 Backlog paper, printed Section A = Sets 5–8 and printed Section B = Sets 1–4. Do not walk into the exam relying only on the letters from an older paper.

7-day crash plan

One week to exam

Day 1

ILD

One beam + one frame ILD. Write all x-ranges and label key ordinates.

Day 2

Three-Moment + Cable

One settlement/variable-I beam + one unequal-support cable.

Day 3

Portal + Cantilever

Memorize assumptions, then complete one frame with diagrams.

Day 4

Wind + Earthquake

Build both floor tables from a recent paper and verify all totals.

Day 5

Deflection

One unit-load frame + one conjugate-beam numerical + proof.

Day 6

Truss + Arch

Selected truss members + one arch N/Q/M problem.

Day 7

Backup + Mock

Stability/SFD and space-truss backup; then a timed 3+3 set selection mock.
